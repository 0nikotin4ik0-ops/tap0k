# Тапок

Казуальная аркада для Яндекс Игр: мухи лезут на еду, ты их шлёпаешь тапком, между волнами покупаешь оружие.
Один палец/мышь, мгновенный дофамин, короткие волны.

## Быстрый старт

Открой `index.html` двойным кликом — игра запустится в локальном режиме (SDK-заглушка, реклама и авторизация выключены).
Чтобы принудительно включить локальный режим на хостинге, добавь `?local=1`.

## Тесты

```
node test/smoke.js          # логика: меню -> волна -> магазин -> покупки -> ресайз
node test/balance.js 0.85   # бот сам играет забег и печатает, до какой волны дожил
```

Смоук-тест подделывает canvas/DOM (общий стенд — `test/harness.js`) и прогоняет настоящий игровой цикл.
Никаких зависимостей не требуется. `test/balance.js` принимает навык бота 0..1 и число забегов:
`0.55` — новичок, `0.85` — уверенный игрок, `0.97` — скилловый. Так проверяются правки баланса:
меняешь цифры в игре — и сразу видишь, как сдвинулась кривая сложности.

## Скриншоты

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\shots.ps1
```

Снимает 6 экранов, широкую раскладку и иконку игры (`promo/icon-512.png`, `icon-1024.png`) в `promo/`. Как это устроено: `tools/frame.html` кладёт игру в iframe
точного размера (старый headless Edge игнорирует `--window-size` и растягивает битмап), `tools/crop.py`
вырезает кадр нужного размера. В этом окружении браузеру нужны именованные каналы, поэтому скрипт
запускается с полным доступом.

Отладочные позы для скриншотов и быстрой проверки состояний:

```
index.html?local=1&fresh=1&pose=wave      # menu | howto | wave | boss | shop | gameover
```

`fresh=1` сбрасывает прогресс перед позой, чтобы кадр был воспроизводимым.

## Сборка архива

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

На выходе `dist/tapok.zip` с `index.html` в корне, без пробелов и кириллицы в именах. Лимит платформы — 100 МБ.
(В PowerShell 7 та же команда работает как `pwsh -File .\build.ps1`.)

## Структура

```
index.html      точка входа + подключение SDK Яндекс Игр
css/style.css   фуллскрин-канвас, запрет скролла и выделения
js/ysdk.js      обёртка SDK: init, LoadingAPI.ready, GameplayAPI, реклама, авторизация, облако
js/i18n.js      строки ru/en, язык определяется через SDK
js/save.js      прогресс: монеты, рекорды, оружие, улучшения, достижения, ежедневный бонус
js/audio.js     все звуки синтезируются WebAudio, ни одного файла-ассета
js/fx.js        партиклы, всплывающие тексты, отпечатки, тряска, hit-stop
js/input.js     pointer events, мультитач, свайп-шлепки, курсоры
js/weapons.js   оружие, характеристики, отрисовка курсора
js/flies.js     мухи, таракан и босс-оса: спавн, ИИ, поедание еды, шлепки
js/ui.js        панели, кнопки, иконки
js/game.js      движок: состояния, волны, экономика, магазин, реклама, интерфейс
test/harness.js стенд: фейковый DOM и canvas, ручной прогон кадров
test/smoke.js   смоук-тест логики
test/balance.js бот-игрок: измеряет кривую сложности
tools/          съёмка скриншотов и иконки (headless Edge + Pillow)
```

## Выкладка в Яндекс Игры

1. `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1` → `dist/tapok.zip`.
2. [Консоль разработчика](https://games.yandex.ru/console) → **Создать игру** → загрузить архив.
3. Заполнить черновик:
   - **Как играть**: «Тапай или свайпай по мухам — тапок бьёт в точке касания. Серия быстрых шлепков даёт комбо-множитель до x9. Муха, которая доела еду, отнимает терпение. Между волнами покупай оружие и улучшения за монеты — они остаются навсегда.»
   - **Жанр**: аркады / казуальные.
   - **Ориентация**: любая (игра адаптируется), устройства: мобильные + десктоп.
   - **Возрастной рейтинг**: 0+.
   - **Облачные сохранения**: включить (в игре они используются при авторизации).
4. Иконка 512×512 — уже готова: `promo/icon-512.png`. Скриншоты — `promo/01-menu.png` … `promo/07-wide.png`.
5. Отправить на модерацию (обычно 3–5 рабочих дней).

## Что уже закрыто из требований платформы

- SDK встроен, `LoadingAPI.ready()`, `GameplayAPI.start/stop`, звук глушится при потере фокуса.
- Гостевой вход, прогресс в `localStorage` пишется сразу после действия, облако — при авторизации по кнопке.
- Реклама только через SDK и только в логических паузах (после каждой 3-й волны, при выходе из гейм-овера, RV-кнопки с явной наградой).
- Управление жестами и мышью, одна рука, нет системного скролла, выделения и контекстного меню.
- Соотношение игрового поля ограничено 2:1, адаптация под портрет/ландшафт/ресайз.
- Ни одного чужого ассета и ни одной внешней ссылки: вся графика процедурная, звук синтезируется.
- Язык интерфейса определяется через SDK (ru/en).
